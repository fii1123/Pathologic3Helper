# Pathologic3Helper
Pathologic 3 Helper - это программа, предназначенная для редактирования файла сохранения.

Разработана она по причине большого числа багов и спорных решений, которые портят впечатление от игры.

# Что она позволяет менять?

## Основные параметры персонажа
Если с количеством патронов и заряда прототипа все логично, то параметр апатии - это то что является "Зависимостью".

Нормой является 0.84. Чем выше этот показатель - тем эффективней расходники влияют на психику Бакалавра.

## События
В игре есть события, которые никак нельзя исправить (Да, в первую очередь, это улица Люричевой). Далеко не многие могут позволить себе перепроходить игру (~ 90 часов геймплея) с нуля.

По мере возможности будут добавляться и другие события.

## Шабнак
Одно из самых спорных решений разработчиков. Поначалу бегать от 3х метровой барышни интересно, но на 3й раз это уже наскучивает.
Особенно из за рандома.

В одном забеге ты тратишь полчаса на поиск исторчника заражения, чтобы потом понять что он, не активен вообщее (или не подсвечивается).
В другом забеге ты проводишь всю опрацию от извлечения пробы, заготовки снаряда и ловле Шабнак менее 4х минут!

Это все пол беды. Данный элемент геймплея является обязательным, а не второстепенным. От есть тебе нужно всю эту операцию проделать 7-9 раз.

ИМХО, побегать в прологе разок можно (один раз, я имею ввиду, поймать с зарядом), а далее можете Её выключить. Ничего от этого не потеряете.

# Как работает программа?

Кнопка автопоиска сама найдет свежий файл сохранения. Но если что-то пойдет не так, можно выбрать файл вручную.

Файл распаковывается во временную директорию програмы, откуда подгружаются параметры.

После нажатия на кнопку "Применить", содержимое временной директории будет переписано в выбранный файл сохранения.
